# reywechat

**reywechat** 是一个基于微信客户端 Hook 程序的微信客户端调用框架。

本包依赖 **reywechat-hook** 提供的 Hook 程序运行。两个程序需要同时运行，通过程序间通信实现对微信客户端的控制和调用。

提供微信客户端调用、消息接收、消息发送、消息触发、数据库记录、文件缓存、消息日志等常用能力，并通过统一的微信对象和模块化设计，简化微信客户端相关功能的开发。

## 特性

* 基于微信客户端 Hook 程序实现微信客户端调用
* 提供统一的微信客户端对象
* 支持微信客户端程序集成和启动
* 提供微信消息异步接收机制
* 支持基于线程池的消息批量接收
* 提供微信消息发送队列
* 支持基于队列的消息发送
* 支持拟人化消息发送操作
* 提供消息接收触发器
* 支持注册消息处理器
* 提供微信消息对象统一处理
* 支持文本、文件等多种消息数据处理
* 支持文件缓存及文件索引
* 提供微信消息及联系人数据库记录
* 提供微信消息接收和发送日志
* 支持日志打印及文件记录
* 提供微信用户及群信息获取
* 支持微信文件下载
* 提供消息回复等便捷操作
* 提供常用微信客户端调用方法

## 安装

要求 **Python 3.12 或更高版本**。

```bash
pip install reywechat
```

---

## 快速开始

最基本的使用方式：

```python
from reywechat import WeChat

wechat = WeChat(**args)

wechat.start()
wechat.keep()
```

其中：

* `WeChat`：reywechat 提供的顶层微信客户端对象
* `args`：微信对象初始化参数
* `start()`：启动微信客户端相关程序集，包括消息接收队列和消息发送队列守护线程
* `keep()`：阻塞当前主线程，使程序持续运行

`WeChat` 对象提供微信客户端功能的顶层封装，可以通过其它模块提供的对象和方法完成消息接收、消息发送、用户信息获取、文件处理等操作。

> **注意：** reywechat 依赖 `reywechat-hook` 提供的 Hook 程序。使用 reywechat 时，需要同时运行 reywechat 程序和 Hook 程序。

# 模块

reywechat 按功能划分为多个模块，各模块负责不同的微信客户端调用和消息处理能力。

## `rall` — All import methods

**统一导出模块。**

提供 reywechat 所有模块方法和对象的便捷导出，可以通过该模块集中导入框架提供的功能，减少从多个模块分别导入的代码。

---

## `rbase` — Base methods

**基础方法模块。**

提供其它模块共用的依赖方法和基础功能。

主要用于为其它模块提供公共依赖及基础处理能力。

---

## `rcache` — Cache methods

**缓存模块。**

提供微信客户端相关的数据缓存能力。

主要包括：

* 微信接收消息文件缓存
* 文件索引管理
* 文件存储管理
* 防止相同文件重复存储

通过文件缓存对象，可以对接收到的微信文件进行统一索引和存储，减少重复文件的存储。

---

## `rclient` — Client methods

**微信客户端模块。**

提供微信客户端调用集成方法。

该模块基于与 Hook 程序之间的通信实现微信客户端控制和调用，是 reywechat 与微信客户端进行交互的主要模块。

主要功能包括：

* 微信客户端调用
* Hook 注入
* 消息回调
* 各类微信消息发送
* 获取用户信息
* 获取群信息
* 下载微信文件
* 其它微信客户端操作

---

## `rdb` — Database methods

**数据库模块。**

提供微信相关数据的数据库记录对象。

用于对微信消息、联系人等数据进行统一的数据库记录和管理。

主要功能包括：

* 微信消息记录
* 联系人记录
* 数据自动新增
* 数据自动修改
* 数据自动删除
* 数据库记录对象

---

## `rlog` — Log methods

**日志模块。**

提供微信消息相关的日志记录能力。

主要用于记录微信消息的接收和发送情况。

主要功能包括：

* 微信接收消息日志
* 微信发送消息日志
* 控制台日志打印
* 日志文件记录

---

## `rreceive` — Receive methods

**消息接收模块。**

提供微信消息接收及消息对象处理能力。

基于线程池实现异步批量消息接收，并将接收到的消息封装为统一的微信消息对象。

微信消息对象提供多种消息数据和操作的集成处理能力。

主要包括：

* 微信消息异步接收
* 基于线程池的批量消息处理
* 微信消息对象
* 消息文本数据
* 文件数据
* 文件传输状态
* XML 数据
* 聊天窗口信息
* 消息发送者信息
* 其它用户引用信息
* 消息内容描述
* 消息回复方法

---

## `rsend` — Send methods

**消息发送模块。**

提供微信消息发送队列及消息发送对象。

消息发送基于队列进行管理，并通过拟人化操作降低连续、快速操作可能带来的风险。

主要功能包括：

* 微信消息发送队列
* 消息发送参数对象
* 各类消息发送方法
* 消息发送状态
* 队列任务管理
* 拟人化消息发送

---

## `rtrigger` — Trigger methods

**消息触发模块。**

提供微信接收消息触发器对象，用于根据接收到的微信消息触发对应的处理程序。

主要功能包括：

* 注册消息处理器
* 接收消息触发
* 消息处理框架
* 异步消息处理协调

通过统一的触发器处理框架，可以减少直接处理异步消息时产生的问题。

---

## `rwechat` — WeChat methods

**顶层微信模块。**

提供 reywechat 的顶层 `WeChat` 对象，是使用框架的主要入口。

主要功能包括：

* 创建微信客户端对象
* 集成其它模块功能
* 启动微信客户端程序集
* 启动消息接收队列
* 启动消息发送队列
* 保持程序持续运行

基本使用方式：

```python
from reywechat import WeChat

wechat = WeChat(**args)

wechat.start()
wechat.keep()
```

其中，`start()` 会启动消息接收队列和消息发送队列的守护线程，`keep()` 会阻塞当前主线程，使微信客户端程序持续运行。
